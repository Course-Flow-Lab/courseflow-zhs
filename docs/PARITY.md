## 自动与页面验证

两个仓库克隆到相邻目录后分别执行（`courseflow-framework` 与 `courseflow-zhs`）：

```sh
# courseflow-zhs
cargo +stable test --locked
cargo +stable build --release --locked

# courseflow-framework
npm run typecheck
npm run check:web
npm test
```

Rust 为 24 项单元测试和 16 项契约测试，框架为 46 项测试，包含 release 二进制 fixture 链路；没有跳过 Rust 集成。模型测试只访问本机模拟 HTTP 服务。

浏览器走通人工补答、草稿、确认提交、结果回读、Word 下载、模型偏好、可编辑提问草稿、成绩、见面课和复习入口。桌面及 390 像素移动布局无横向溢出，长页面固定侧栏与独立内容滚动正常。离线界面的示例成绩不能作为平台完成证据。

本次另在隔离的离线服务把时钟固定为北京时间 23:30，验证夜间开关保存后立即更新且重新加载后保留；问答看板验证数量调节、草稿生成／编辑／选择／删除、刷新统计保留编辑内容、折叠记录及所选草稿确认发布。未修改真实服务中用户的夜间偏好。

## 明确边界

共享课已提交考试没有已确认的只读路径，只支持导出原任务的本地报告。未知平台题型、验证码、人脸、未开放活动、线下见面课和未知控件等待用户在官方页面处理。任务执行结束与平台所有项目达标分别记录，不把未满分或跳过项标为平台成功。

实际账号的进度保存、正式交卷、完整见面课签到、问答发布和真实模型调用仍待用户在部署站点逐项验收。步骤见[本机部署与验收](https://github.com/Course-Flow-Lab/courseflow-framework/blob/main/docs/LOCAL-DEPLOYMENT.md)。
